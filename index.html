1. ¿Qué entienden por sistema de información?

Entendemos que un sistema de información es un conjunto de elementos que trabajan de manera organizada para recopilar, procesar, almacenar y presentar información útil. Puede incluir personas, programas, equipos tecnológicos y datos que ayudan a realizar actividades y tomar decisiones.

2. ¿Cuál es la diferencia entre un dato y una información?

Un dato es un valor o un hecho aislado que todavía puede no tener un significado claro. La información se obtiene cuando los datos se organizan y se interpretan para comprender una situación.

Ejemplo:

El número 150 es un dato. Si sabemos que una tienda vendió 150 productos durante un día, ese dato se convierte en información que permite conocer el nivel de ventas.

3. ¿Qué elementos consideran que forman parte de un sistema de información?

Consideramos que los principales elementos son las personas, los datos, el hardware, el software, los procedimientos y las redes de comunicación. Todos cumplen una función para que el sistema pueda recibir datos, procesarlos, almacenarlos y mostrar resultados.

4. Mencionen dos sistemas de información que utilicen con frecuencia.

Primer ejemplo: Aplicación bancaria

Permite consultar el saldo de una cuenta, revisar movimientos y realizar transferencias. Utiliza información financiera para mostrar al usuario el estado de sus operaciones.

Segundo ejemplo: Plataforma educativa

Permite consultar tareas, revisar calificaciones, descargar materiales y recibir avisos de los docentes. Organiza la información académica de estudiantes y profesores.

5. ¿Cuál consideran que es la función de una base de datos dentro de un sistema de información?

Una base de datos permite guardar y organizar la información para consultarla, modificarla y mantenerla disponible cuando sea necesaria. Por ejemplo, una institución educativa puede almacenar los datos de sus estudiantes, las asignaturas y las calificaciones para acceder a ellos de forma organizada.

6. ¿Cómo podría ayudar un sistema de información a una empresa que necesita controlar clientes, ventas e inventario?

El sistema podría reunir los datos de los clientes, registrar las ventas y actualizar las cantidades de productos disponibles. De esta manera, la empresa tendría un mejor control de sus operaciones, podría identificar los productos que necesita reponer, consultar el historial de compras y reducir errores al registrar información manualmente.

7. Términos relacionados con los sistemas de información y el desarrollo de software

ERP

Es un sistema que integra diferentes áreas de una empresa, como ventas, compras, contabilidad e inventario, para administrar sus operaciones desde un mismo entorno.

CRM

Es una herramienta que ayuda a gestionar la relación con los clientes, registrar sus datos y realizar seguimiento de las ventas y la atención que reciben.

Aplicación web

Es un programa al que se accede mediante un navegador y que permite realizar actividades a través de internet o de una red local.

Aplicación móvil

Es un programa diseñado para utilizarse en dispositivos móviles, como teléfonos inteligentes y tabletas.

Computación en la nube

Es una forma de utilizar recursos tecnológicos, como almacenamiento, servidores y aplicaciones, a través de internet sin depender únicamente de un equipo local.

API

Es una interfaz que permite que dos programas se comuniquen e intercambien datos o soliciten funciones entre sí.

UML

Es un lenguaje de modelado que utiliza diagramas para representar la estructura y el comportamiento de un sistema de software.

Scrum

Es un marco de trabajo que organiza el desarrollo de proyectos en periodos cortos, con revisiones frecuentes y colaboración entre los integrantes del equipo.

Kanban

Es un método visual para organizar tareas y observar su avance mediante estados como pendiente, en proceso y terminado.

8. ¿Qué entienden por requerimiento de un sistema de software?

Un requerimiento es una necesidad o condición que debe cumplir un sistema para satisfacer las expectativas de sus usuarios. Puede indicar una función que debe realizar el programa o una característica que debe tener, como la seguridad, la rapidez o la facilidad de uso.

Ejemplo: Un sistema de ventas debe permitir registrar productos y calcular el total de una compra.

9. ¿Para qué creen que sirve realizar diagramas o modelos antes de desarrollar un sistema?

Los diagramas y modelos ayudan a planificar y comprender cómo funcionará el sistema antes de comenzar a programarlo. Permiten identificar sus componentes, organizar los procesos, visualizar las relaciones entre los elementos y detectar posibles problemas con anticipación. También facilitan la comunicación entre las personas que participan en el proyecto.

10. ¿Qué metodología, enfoque o forma de trabajo para desarrollar software conocen?

Conocemos de manera general las metodologías ágiles, que permiten desarrollar software mediante entregas progresivas, revisión de resultados y colaboración entre los integrantes del equipo. Entre sus enfoques se encuentran Scrum y Kanban, que ayudan a organizar las actividades y dar seguimiento al avance del trabajo.
