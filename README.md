## Descripción

Esta es una evaluación diagnóstica sobre sistemas de información que incluye:
- **index.html**: Evaluación diagnóstica con 10 preguntas y respuestas
- **punto2.html**: Análisis del video sobre sistemas de información

## Características

✨ **Diseño responsivo** - Adaptado para dispositivos móviles, tablets y desktop
🎨 **Estilos modernos** - Colores, tipografía y distribución visual profesional
🔗 **Navegación fluida** - Enlaces entre páginas para fácil acceso

## Cómo desplegar en Vercel

### Opción 1: Usando el dashboard de Vercel

1. Ve a [vercel.com](https://vercel.com)
2. Inicia sesión con tu cuenta
3. Haz clic en "Add New Project"
4. Selecciona tu repositorio de GitHub
5. Haz clic en "Deploy"

### Opción 2: Usando la CLI de Vercel

```bash
# Instala la CLI de Vercel (si no la tienes)
npm install -g vercel

# Navega a la carpeta del proyecto
cd pagina_trabajo_grupal

# Despliega el proyecto
vercel
```

Vercel detectará automáticamente que es un proyecto HTML estático y lo desplegará.

## Cómo usar localmente

1. Abre `index.html` en tu navegador
2. Haz clic en el botón "Ver análisis del video (Punto 2)" para ir a la segunda página
3. Usa el enlace "← Volver a la evaluación diagnóstica" para regresar
